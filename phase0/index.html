PHASE 0 — 助走

2級の勉強を始める前に、
足場を固める12時間

8月27日（木）〜 8月30日（日）。ここは新しい論点を覚える時間ではなく、この先11週間ずっと使い続ける土台を作る時間です。

全12時間 4日間 4ユニット 3級合格済みが前提
なぜ助走期間を置くのか

2級のテキストをいきなり開くと、たいてい2つの場所でつまずきます。ひとつは3級の知識が抜けていること。2級の試験は3級の範囲もそのまま出題対象なのに、市販の2級テキストは3級の範囲を載せません。消費税の精算・法人税等・貯蔵品・剰余金の配当・伝票会計あたりが素通りされ、第3問（決算）で効いてきます。もうひとつは工業簿記が「何をやっているのか分からない」まま進んでしまうこと。工業簿記はすべての論点が1枚の図（勘定連絡図）の上に乗っていて、その図が頭に入っていないと、個々の計算がバラバラの暗記事項に見えてしまいます。

この12時間は、その2つを先に潰しておくための時間です。加えて、電卓の使い方と、教材・受験申込という後回しにすると効いてくる事務作業もここで片づけます。

14つのユニット

UNIT 01 ／ 4時間
3級の総復習

仕訳の考え方を言語化し直し、決算整理9項目を一気に通す。消費税・法人税等・貯蔵品・剰余金の配当・伝票会計といった、2級テキストが載せない3級論点もここで塞ぐ。精算表と帳簿の締切まで通し、決算整理の出口を作る。

仕訳ドリル 30問商業簿記
UNIT 02 ／ 4時間 ★最重要
勘定連絡図を描けるようにする

材料費・労務費・経費 → 仕掛品 → 製品 → 売上原価。工業簿記40点分の全論点が乗る1枚の地図を、何も見ずに描ける状態にする。

インタラクティブ図解穴埋めモード工業簿記
UNIT 03 ／ 2時間
電卓トレーニング

M+ / M− / MR / GT と定数計算。2級は3級より計算量が跳ね上がり、電卓の使い方がそのまま所要時間に直結する。初日に本番用の1台を決める。

実習ドリルキー手順つき
UNIT 04 ／ 2時間
教材の調達・受験申込・環境整備

2級は試験問題が公開されない。実戦教材をどう組むかと、締切が地域ごとに違う受験申込。「確認した」で止めず「完了」まで持っていく。

24日間の割り振り

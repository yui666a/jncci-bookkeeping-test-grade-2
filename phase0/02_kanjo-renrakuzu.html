1なぜ、1枚の図から始めるのか

3級で学んだ商業簿記は、ものすごく単純化すると「買ってきたものを、そのまま売る」商売の記録でした。100円で仕入れた商品を150円で売る。仕入と売上の2つの勘定があれば、話はだいたい片づきます。

工業簿記が扱うのは「材料を買ってきて、工場で加工して、製品にしてから売る」商売です。買ったものと売ったものが同じ形をしていません。鋼板とタイヤとネジを買ってきて、工員が組み立て、機械を動かし、工場の電気を使い、その結果「自動車」という別のものが出てくる。

ここで問題が起きます。売った自動車1台の原価は、いくらなのか。買ってきた鋼板の値段でもなければ、払った電気代でもありません。いろいろな費用が形を変えながら合流して、1台の原価になっています。その合流のしかたを記録するために、商業簿記にはなかった勘定が増えます。増えた勘定とその間の流れを1枚にまとめたものが、勘定連絡図です。

勘定連絡図かんじょうれんらくず

材料費・労務費・経費が、製造間接費や仕掛品を経由して製品になり、最後に売上原価になるまでの流れを、勘定どうしの矢印で表した図。工業簿記の全論点は、この図のどこかを詳しく計算しているにすぎません。

なぜ、いきなり個々の計算を覚えないのか

工業簿記のテキストは、費目別計算 → 部門別計算 → 個別原価計算 → 総合原価計算 → 標準原価計算 → 直接原価計算、という順で進みます。これを図なしで読むと、それぞれが独立した計算パズルに見えます。「平均法と先入先出法」「シングルプランとパーシャルプラン」「予定配賦率」…… 用語が積み上がるだけで、何のためにやっているのか分からなくなる。これが工業簿記で挫折する典型パターンです。

先に図を入れておくと、話が変わります。新しい論点が出てきたとき「ああ、これは図のこの矢印の計算方法の話だな」と位置づけられる。位置が分かれば覚える量が激減します。だからこのユニットに4時間かけます。

配点との関係

2級の配点は 第1問20点／第2問20点／第3問20点／第4問28点／第5問12点とされています（日商は各問の配点を事前に公表しておらず、第4問28点・第5問12点は予備校分析による通説です。詳しくは UNIT 04）。いずれにせよ第4問と第5問の40点が工業簿記です。商業簿記の60点は範囲が広く、どこが出るか読みにくい。一方の工業簿記は範囲が狭く、出題パターンがほぼ固定されています。つまり投下時間あたりの得点効率が最も高いのが工業簿記で、その工業簿記の入口がこの図です。

2工業簿記が扱っているもの — 原価の分類

図の話に入る前に、図の上を流れる「モノ」の正体をはっきりさせます。流れているのは原価です。

原価げんか

製品を作るためにかかった金額のこと。より正確には「製造原価」。工場で製品を作るために消費した、材料・人手・その他のすべてを金額に置き換えたものです。

分類その1 — 何を消費したか（形態別分類）

まず、何を消費したのかで3つに分けます。これを形態別分類といいます。

形態別分類 ①

材料費

モノを消費した分。鋼板、木材、小麦粉、ネジ、接着剤、機械油、工場の軍手。

形態別分類 ②

労務費

人手を消費した分。工員の賃金、工場長の給料、工場事務員の給料、法定福利費。

形態別分類 ③

経費

材料費でも労務費でもない残り全部。工場の電気代・水道代、工場建物の減価償却費、外注加工賃、工場の火災保険料。

この3つは「消去法」で覚えると速いです。モノなら材料費、人なら労務費、それ以外は全部経費。

分類その2 — どの製品のものか分かるか（製品との関連による分類）

次に、まったく別の切り口で2つに分けます。その原価が、どの製品にいくらかかったか特定できるかどうかです。

製品との関連 ①

直接費

「この製品にいくら使った」とはっきり分かるもの。パン工場なら、あんパンに使った小麦粉とあんこ。1個あたりの使用量が分かるので、そのまま製品の原価にできます。

製品との関連 ②

間接費

分からない、または分けても意味がないもの。パン工場の電気代を「あんパンの分」「食パンの分」に分けることはできません。オーブンは全部のパンを一緒に焼いています。

この2つを掛け合わせると、6種類になる

形態別の3つ × 製品との関連の2つ ＝ 6つの分類。工業簿記の原価は、必ずこの6つのどれかに入ります。

なぜ、直接と間接を分けるのか

直接費は簡単です。「あんパンに小麦粉を3,000円分使った」と分かっているので、そのまま「あんパンの原価は3,000円ぶん増えた」と記録すればいい。まっすぐ仕掛品勘定に入れられます。

困るのは間接費です。工場の電気代80,000円を、あんパンと食パンとクロワッサンに、どう分ければいいのか。実際のところ、正確には分けられません。だからやり方を変えます。いったん「製造間接費」という1つの箱に全部集めてから、何らかの基準（作業時間、機械の運転時間など）で「えいや」と割り振る。この割り振りのことを配賦といいます。

つまり、直接費と間接費を分ける理由は通り道が違うからです。直接費は仕掛品へ直行、間接費は製造間接費を経由して配賦。この「2本の通り道」が、これから描く図の骨格になります。

配賦はいふ

1か所に集めた製造間接費を、一定の基準にしたがって各製品（各製造指図書、各部門）に割り当てること。「配布」ではなく「配賦」と書きます。

製造原価に入らないもの

ここが最初の大きな落とし穴です。会社で発生する費用がすべて製造原価になるわけではありません。

「工場で発生したかどうか」が境目

本社の経理部の事務員の給料、本社建物の減価償却費、営業所の家賃、広告宣伝費、販売員の給料、製品の発送費 ── これらは製造原価ではありません。販売費及び一般管理費（販管費）です。製品を作るためにかかった費用ではなく、売るため・会社を運営するためにかかった費用だからです。

判断の物差しはシンプルで、その費用は工場で発生したか。工場で発生していれば製造原価、そうでなければ販管費。

ひっかけの定番：「工場の事務員の給料」は間接労務費（製造原価に入る）。「本社の事務員の給料」は販管費（入らない）。同じ「事務員の給料」でも、工場か本社かで扱いが正反対になります。「工場の」「本社の」という一言を、問題文で必ず確認してください。

この違いは図の上でも見た目に表れます。製造原価は 材料・賃金・経費 → 仕掛品 → 製品 → 売上原価 という長い道を通りますが、販管費はその道をまったく通らず、月次損益に直行します。

3勘定連絡図の全体像

これが、これから11週間ずっと使う1枚です。まずは眺めて、それから箱をクリックしてください。その勘定の意味・借方と貸方に入るもの・代表的な仕訳・つまずきポイントが、図の下に出ます。

箱をクリック／Tabで移動してEnter

工業簿記の勘定連絡図。左から右へ、原価が形を変えながら流れていく。箱をクリックすると、その勘定の解説が下に表示されます。

この図の読み方

  1. 左端の3つは「何を消費したか」の受け皿材料・賃金・給料・経費。工場で発生した原価は、まずこの3つのどれかに入ります。ここが形態別分類（材料費・労務費・経費）に対応しています。
  2. そこから道が2本に分かれる直接費は仕掛品へまっすぐ。間接費は製造間接費へ。この分岐が製品との関連による分類（直接費・間接費）に対応しています。左の3つの箱それぞれから2本ずつ、合計6本の矢印が出るのは、原価が6つに分類されるからです。
  3. 製造間接費で合流し、配賦されて仕掛品へ合流するいったん1か所に集めた間接費を、基準にしたがって割り振る。この矢印1本が、のちに「予定配賦」「差異分析」「部門別計算」という大論点になります。
  4. 仕掛品にすべてが集まる直接材料費・直接労務費・直接経費・製造間接費配賦額。これに月初仕掛品を足したものが、仕掛品勘定の借方合計です。図の中心はここです。
  5. 完成した分だけが製品へ出ていく仕掛品の借方合計から月末仕掛品を引いた残りが、当月完成品原価。まだ作りかけの分は仕掛品に残ります。
  6. 売れた分だけが売上原価へ出ていく製品の借方合計から月末製品を引いた残りが、当月売上原価。売れ残りは製品として資産に残ります。
  7. 売上原価は月次損益で締められるここでようやく費用になり、売上高と対応させて利益が出ます。販売費及び一般管理費は、この長い道を通らずに直接ここへ来ます。
「入って、出て、残る」がすべての箱で同じ

材料・仕掛品・製品の3つは、構造がまったく同じです。借方＝月初有高＋当月の増加／貸方＝当月の減少＋月末有高。そして「当月の減少」は、借方合計から月末有高を引けば求まります。この形は3級の商品有高帳とまったく同じ考え方です（帳簿の書き方を思い出せなくても構いません。「月初にあった分＋入ってきた分−残っている分＝出ていった分」という引き算の形だけが要ります）。新しいことは何も起きていません。

なお、材料を払い出すときの単価をどう決めるか（先入先出法・移動平均法）は、W1の材料費で改めて扱います。ここでは金額の出入りの形だけを押さえてください。

賃金・給料だけは、月初と月末が左右逆に入る

この「月初は借方、月末は貸方」という形を覚えた直後に、必ずつまずく箱があります。賃金・給料です。ここだけは月初未払が貸方、月末未払が借方と、材料・製品とちょうど逆になります。

理由は、そこに乗っているものが「モノ」ではなく「負債」だからです。材料勘定の月初有高は、月初に手元にある材料という資産なので借方に置きます。ところが賃金勘定の月初未払は、前月働いてもらったのにまだ払っていない負債です。負債のホームポジションは貸方ですから、月初の残高も貸方から始まります。

もう一つの見方もあります。賃金勘定の借方に来るのは「当月に支払った金額」です。その支払額には、前月ぶんの未払を精算した分が混ざっています。だから月初未払は借方から差し引く＝貸方に置くことになります。逆に当月働いてもらったのにまだ払っていない月末未払は、支払額に含まれていないので借方に足します。

消費額＝当月支払高−月初未払＋月末未払

「箱の中身が資産なら月初は借方、負債なら月初は貸方」——この1行で判断できます。式を丸暗記すると符号を逆に覚えて必ず崩れるので、どちらなのかを毎回考えてください。

売上の仕訳と売上原価の仕訳は「2本セット」

3級の三分法では、売ったときに売上だけを記録し、原価は決算で一括計算していました。工業簿記では売った瞬間に、売価の仕訳と原価の仕訳を2本立てます（売上原価対立法と同じ考え方）。片方を書き忘れる人が非常に多い場所です。

T字勘定で貸借を確認する

ここまでの流れを勘定の形で並べます。どの勘定も左右の合計が一致していることを、自分の目と電卓で確かめてください。

5この図の上に、これから学ぶ論点がどう乗るか

ここが、このユニットに4時間かける最大の理由です。工業簿記のすべての論点は、この図のどこかを詳しくしているだけです。先に対応関係を見ておいてください。

論点図のどこの話か学ぶ時期
費目別計算
材料費・労務費・経費		 左端の3つの箱そのもの。「消費額をいくらと計算するか」（材料の払出単価、賃率、経費の測定）が中身です。 W1〜W2
製造間接費の予定配賦・差異分析 製造間接費の箱。実際に発生した額（借方）と、あらかじめ決めた率で配賦した額（貸方）がズレるので、その差を予算差異・操業度差異に分けて説明します。 W3
部門別計算 製造間接費と仕掛品のあいだに、部門費の箱が割り込みます。製造間接費 → 各部門 → 仕掛品。箱が1段増えるだけで、流れは変わりません。 W4
個別原価計算 仕掛品の箱の中身を、製造指図書ごと（No.101・No.102…）に分けて管理します。原価計算表がその明細です。 W4
総合原価計算 仕掛品の箱の中の計算方法。「月末仕掛品をいくらにするか」を、完成品換算量・平均法・先入先出法で決めます。工程別・組別・等級別はその応用です。 W5
標準原価計算 各箱に、実際の原価ではなく「あるべき原価」を入れます。実際との差を差異として抜き出し、材料・労務費・製造間接費それぞれで原因を分析します。 W6
直接原価計算 図の一部を組み替えます。固定製造原価を製造原価から外し、期間費用として直接に損益へ流す。仕掛品・製品を通る金額が変わります。 W7
本社工場会計 この図を、工場側の帳簿として切り出します。工場の帳簿には材料・仕掛品・製品が置かれ、本社との間は本社勘定・工場勘定でつなぎます。図そのものは変わりません。 W7
この表の使いかた

W1以降、新しい論点に入るたびに、この表に戻ってきてください。「いま自分は図のどこを勉強しているのか」を毎回確認する。それだけで、工業簿記は「バラバラな計算の集まり」ではなく「1つの話」として頭に入ります。

本番の第4問・第5問でも同じです。問題文を読んで最初にやるのは、余白に図を描いて「今回聞かれているのはこの矢印だ」と当たりをつけることです。

6描く練習

ここからがこのユニットの本体です。読んで分かった気になっても、白紙に描けなければ本番では使えません。紙とペンを用意してください。

描く手順

  1. 両端に杭を打つ紙の左端に「材料」「賃金・給料」「経費」の3つを縦に並べ、右端に「売上原価」を書きます。この4つが図の外枠です。ゴールから先に決めると、途中が迷子になりません。
  2. 真ん中に仕掛品図の中心。左3つと売上原価のちょうど中間あたりに置きます。
  3. 仕掛品と右端の間に製品仕掛品 → 製品 → 売上原価 の3つが横一列に並びます。
  4. 左3つと仕掛品の間の「上」に製造間接費ここが図の立体感を作る場所。仕掛品の真上あたりに置きます。
  5. 直接費の矢印を3本、仕掛品へ材料 → 仕掛品（直接材料費）、賃金・給料 → 仕掛品（直接労務費）、経費 → 仕掛品（直接経費）。矢印の横に費目名を書きます。
  6. 間接費の矢印を3本、製造間接費へ材料 → 製造間接費（間接材料費）、賃金・給料 → 製造間接費（間接労務費）、経費 → 製造間接費（間接経費）。左の3つの箱それぞれから2本ずつ出ている状態になります。
  7. 製造間接費から仕掛品へ、配賦の矢印矢印の横に「配賦」と書きます。この1本が第4問の頻出論点です。
  8. 仕掛品 → 製品 → 売上原価矢印の上に「当月完成品原価」「当月売上原価」と書いて完成。余力があれば、売上原価 → 月次損益 まで。
順番に決まりはないが、毎回同じ順で描く

上の手順が唯一の正解ではありません。左から順に描く人もいれば、仕掛品を先に置く人もいます。大事なのは毎回まったく同じ順序で描くことです。順序を固定すると手が順番を覚えて、本番では考えずに手が動きます。逆に毎回違う順で描いていると、いつまでも「次はどこだっけ」と考え続けることになります。

目標時間は90秒。本番の答案用紙の余白に、90秒で描けるようにしておくと、第4問・第5問の見通しが劇的に良くなります。

描いたあとに必ずやる自己チェック

描き終えたら、次の4点を自分で点検してください。①左の3つの箱から矢印が2本ずつ、合計6本出ているか／②その6本のうち3本が仕掛品、3本が製造間接費に向かっているか／③製造間接費から仕掛品への矢印に「配賦」と書いたか／④仕掛品と製品の箱に「月初」「月末」を書き添えたか。抜けるのはたいてい④です。

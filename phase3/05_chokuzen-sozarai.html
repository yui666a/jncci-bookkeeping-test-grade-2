1直前週にやること・やらないこと

マラソンの前の週に、走り込みの距離を増やす人はいません。増やしても本番までに脚が回復せず、疲れを残したままスタートすることになります。やるのは短い距離を軽く走って、体に走り方を思い出させておくことだけです。

試験前の1週間も同じです。新しい論点を覚えても、定着する前に本番が来ます。そのうえ「知らないことがまだある」という不安を、自分で増やすことになります。

やること
  • 本番形式のセットを2つ（11/9〜11/12）
  • 頻出仕訳を手で書く（2節・UNIT 06）
  • 勘定連絡図を何も見ずに描く（3節）
  • これまでに間違えた設問をもう一度解く（4節）
  • 解答順を本番と同じ手順で通す
やらないこと
  • まだ触れていない論点に手を出す
  • 新しい問題集を買って始める
  • 11/13（金）以降に本番形式のセットを通しで解く
  • 11/13〜11/15に1日2時間を超えて勉強する
  • 睡眠を削る
なぜ最後の3日は2時間以内なのか

90分の試験は、計算の連鎖を最後まで崩さずに運ぶ集中力の勝負です。試験前の2〜3日の睡眠不足は、知識の量ではなくこの集中力を直接削ります。第3問の最後で貸借が合わない、第4問(2)で換算量を1か所取り違える、という形で点に出ます。

一方で、この時期に増やした1時間でできるのは、既習の論点をもう一度なぞることです。それは11/12までのセットと解き直しで一通り済んでいます。増やした1時間で得られるものは小さく、睡眠を削って失うものは90分全体に及ぶ。この非対称があるので、勉強時間の側に上限を置きます。

2頻出仕訳の総ざらい（商業簿記）

第1問の20点と、第3問の決算整理の土台になる仕訳です。1問ずつ、科目を挙げる → 増減を判定する → 左右を決める → 貸借一致を確かめるの4ステップで書いてください。迷った問は、解説の最後にある単元に戻ります。

工業簿記の仕訳（第4問(1)の12点）は UNIT 06 にまとめてあります。両方を同じ日に回してください。

3級の論点と、その上に乗る2級の計算を落とさない

2級の試験範囲は3級の範囲を含んでいます。次の論点は3級の範囲なので2級のテキストには載っていませんが、第1問・第3問・第2問（株主資本等変動計算書）でよく使います。

  • 消費税（税抜方式）の納付額の確定（Q12）
  • 法人税、住民税及び事業税の計上と、仮払法人税等・未払法人税等（Q11）
  • 剰余金の配当と、それに伴う利益準備金の積立の仕訳（Q10）
  • 貯蔵品への振替（未使用の収入印紙・切手）。第3問の決算整理に入る
  • 伝票会計（3伝票制・仕訳日計表）

一方で、同じ論点の中に2級で上乗せされる計算があります。Q10の積立額を「資本金の4分の1に達するまで」で頭打ちにする準備金積立額の算定は2級の論点で、Q11の年税額の元になる課税所得の算定（税引前当期純利益に損金不算入額などを加減する）も2級で初めて学びます。仕訳の形は3級、金額の出し方は2級、と分けて確かめてください。

難しいから落とすのではなく、視界に入らないから落とします。直前週にこそ手で書いておいてください。戻り先は、3級の部分が Phase 0 UNIT 01 の3節（消費税・法人税等・貯蔵品）・4節（剰余金の配当）・6節（伝票会計）、2級の上乗せ部分が Phase 1 UNIT 21（準備金積立額）・Phase 1 UNIT 19（課税所得）です。

3勘定連絡図を何も見ずに描く

工業簿記の論点は、すべて1枚の勘定連絡図の上に乗っています。費目別計算も、総合原価計算も、標準原価計算の差異も、「この図のどこを計算しているのか」が分かっていれば、見慣れない出題でも手が止まりません。直前週にもう一度、何も見ずに描いて確かめます。

  1. 白紙を1枚用意し、90秒を計る。何も見ない。目標時間は Phase 0 UNIT 02 の6節と同じ
  2. 材料・賃金・給料・経費から描き始める。そこから仕掛品・製造間接費、製品、売上原価へと矢印をつなぎ、各矢印の上に何が流れるか（直接材料費・間接労務費・完成品原価など）を書く
  3. Phase 0 UNIT 02 勘定連絡図を開いて見比べる。描けなかった矢印、向きを誤った矢印に印をつける
  4. 余裕があれば、原価差異の行き先を描き足す。材料消費価格差異・賃率差異・製造間接費配賦差異がそれぞれの勘定から取り出され、会計期間末に売上原価へ振り替えられるところまで。この部分は Phase 0 UNIT 02 の図にはないので、Phase 1 UNIT 04 材料費・Phase 1 UNIT 07 労務費・Phase 1 UNIT 10 製造間接費・Phase 1 UNIT 20 標準原価計算の説明と照らし合わせる
  5. 印をつけた矢印の仕訳を、UNIT 06 で書く。描けない矢印は、仕訳でも迷っている場所です

90秒で描き切れなかったら、描けた所までで打ち切って見比べます。90秒は手順2の図の目標で、手順4の原価差異は含みません。時間をかければ描ける図ではなく、本番で問題文を読みながら頭の中に浮かぶ図が目標です。

4間違えた設問をもう一度解く

W11 の4時間は、これまでに間違えた設問の反復に充てます。素材は3つあり、それぞれ持っているものが違います。

素材集まっているもの反復での役割
間違いノートPhase 0 UNIT 04 の6節で作った紙のノート。W1から書きためた誤答が、論点タグ付きで並ぶ何を回すかを決める軸。同じタグの誤答を束ね、件数の多いタグ（構造的な穴）から回す
復習ドリルこの教材のドリルで一度でも間違えた設問。自動で集まるタグに対応する単元で絞り込み、画面で解き直す。ノートに書き写す必要はない
失点の記録UNIT 01 の手順で付けた、Phase 3 のセットの失点。型（知識・読み違い・計算・時間）で分けてある市販の予想問題集で落とした問題を探す索引。自動では集まらないので、ここから引く

回し方は、ノートでタグを選ぶ → そのタグの単元を復習ドリルで解く → 同じタグの市販問題集の失点を記録から引いて解き直すの順です。素材ごとに別々に回すと、同じ穴を3回に分けて見ることになり、それが1つの穴だと気づけません。

復習ドリルの決まり
  • 3回続けて正解すると一覧から消えます。途中で間違えると連続は振り出しに戻ります
  • 並び順は、最後に間違えてから時間が経った順。忘れかけているものが先に来ます
  • もう迷わないと判断した設問は、自分で外せます
  • 単元ごとに絞り込めます。直前週は、大問で最大の配点（通説で28点）を持つ第4問と、上流の1欄の誤りが下流の欄に連鎖して失点が膨らむ第3問にかかわる単元から
市販の問題集で間違えた問題

復習ドリルに集まるのは、この教材のドリルだけです。予想問題集で落とした問題は、UNIT 01 の失点の記録を見て、失点の大きかった型の問題からもう一度解きます。全部を解き直す時間はありません。

どの単元にどれだけ間違いが残っているかは、学習の記録の「要復習」で一覧できます。

教材は最初から同じ開き方で通す

ドリルの正誤・チェック・メモは、ブラウザの保存領域に記録されます。この保存領域は開き方（アドレスの始まり）ごとに別です。手元のHTMLファイルを直接開いた場合（file://）と、公開サイトやローカルサーバー（https://・http://localhost）から開いた場合とでは、記録が共有されません。途中で開き方を変えると、それまでの記録は新しい開き方の側からは見えず、復習ドリルにも要復習が出てきません。

そのうえ復習ドリルは、設問の一覧を別のファイルから読み込むため、file:// では動きません。したがって教材は、最初から公開サイト（GitHub Pages）か、教材のフォルダで python3 -m http.server を実行して表示されたアドレスのどちらかに決め、全単元をその開き方で通してください。

5直前3日と試験当日

日やること上限
11/13（金）頻出仕訳（2節・UNIT 06）を1周 ＋ 間違いの反復（4節）2h
11/14（土）勘定連絡図を描く（3節）＋ 間違えた仕訳だけもう1周 ＋ 間違いの反復（4節）。解答順と大問ごとの目安時間を声に出して確認し、持ち物をそろえる2h
11/15（日）学習は入れない。受験票で集合時刻を確かめ、持ち物を持って会場へ向かう—

11/12までのセットの解き直しが延びたら、平日の上限を超えて続けずに、11/13〜11/14 の間違いの反復の時間を先に充てます。済んでいる問題の解き直しは新しい問題ではないので、この3日の方針に反しません。W11の予備2時間はこの振り替えのための余白で、日割りの枠には置かず、使うときも1日2時間の上限は超えません（Phase 3 目次の W11 の表）。

統一試験の持ち物

  • 受験票（集合時刻・試験開始時刻は会場によって違うので、受験票で確かめる）
  • 身分証明書（氏名・生年月日・顔写真が確認できるもの）
  • 筆記用具：HB または B の黒鉛筆、シャープペン、消しゴム。ラインマーカー・色鉛筆・定規は使えない
  • 電卓またはそろばん（どちらか1つ）。電卓は計算機能（四則演算）のみのもの

出典：日本商工会議所「簿記2級 試験科目・注意事項」（https://www.kentei.ne.jp/bookkeeping/class2/exam、2026年9月24日確認）。受験地の商工会議所から別の指示があれば、そちらに従う。

試験開始の合図のあと

  1. 時刻を問題用紙の隅に書く。終了時刻と、第4問・第5問・第1問・第3問を終える目安の時刻（開始から20分・30分・45分・65分）
  2. 第4問から解き始める。全体を見渡して解く順を考え直さない。順番は何週間も前に決めてある
  3. 目安を5分過ぎた大問は、欄を残して次へ。残した欄は第2問の後で戻る
  4. 最後の5分は、まず空欄を埋め、残った時間で見直す。空欄は確実に0点だが、見直しで誤りが見つかるとは限らない。同じ時間なら、0点が決まっている欄に数字を書くほうが点になる見込みが高い
ここまで来たら、やることは決まっている

解答順も、時間配分も、失点の型への対策も、すでに決めてあります。本番の90分は、決めたことをその通りに実行する時間です。考えることが少ないほど、計算に集中力を回せます。

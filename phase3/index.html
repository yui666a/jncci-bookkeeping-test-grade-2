PHASE 3 — 実戦と直前 ／ W10〜W11

新しいことは習わない。
本番と同じ形で解き、同じ失点を二度しない

Phase 2 までで全論点と、配点の重い第2問・第3問を仕上げました。最後の2週間は新しい論点を1つも足しません。本番と同じ90分・同じ5題の形で解き、その答案を解き直して失点の原因を潰す。やることはそれだけです。途中でネット試験を1回受け、本番の環境も先に経験しておきます。

W10–W11 公開中 2週間で39時間 本番形式6セット 11/15 第174回 統一試験
なぜ最後の2週間を「解き直し」に使うのか

論点ごとの演習と本番の90分は、別の競技です。論点別の問題は「いま何を問われているか」が最初から分かっています。本番では5題が同時に並び、どの論点が来るかも、どこに時間を使うかも自分で決めなければなりません。この判断は、本番と同じ形で解いた回数でしか身につきません。

ただし、解いた回数そのものは点になりません。模試を10回受けても、毎回同じところで同じ失点をしていれば点は伸びないのと同じです。点を伸ばすのは、解いた答案から「なぜ落としたか」を特定し、次のセットまでに潰すことです。

そのため Phase 3 では1セットに4時間を割きます。解答が90分、解き直しが2.5時間。解く時間より解き直す時間のほうが長いのは意図どおりです。セット数を増やして解きっぱなしにするより、6セットを徹底的に潰すほうが本番の点は上がります。

解き直しを「解説を読んで納得する」で済ませない

解説を読むと、分かった気がします。しかしそれは正解を見てから理由を追えただけで、次に白紙から解ける保証にはなりません。解き直しは、解説を閉じて自分の手で答案を最初から書き直せたら終わりです。2.5時間の大半はこの書き直しに使います。

2W10 — 前哨戦（11/2–11/8）

週23時間のうち16時間を本番形式4セットに、2時間をCBTの操作訓練に、残り5時間を復習と予備に充てます。新規インプットは0時間です。

この週にネット試験を1回受けます。これは模試ではなく本物の受験です。合格すればここで終わり、不合格でも本番の1週間前に「90分で5題を解く」本物の緊張を経験できます。統一試験の前後にはネット試験の休止期間があり、第174回に伴う休止は11/9〜11/18です。ネット試験で受けられるのは11/8が最後になります。

予約は受験日の3日前まで

ネット試験の予約・変更・キャンセルは受験日の3日前までで、2日前からはできません。たとえば11/7（土）に受けるなら、予約の期限は11/4（水）です。W10に入ってから会場を探すと、空いている枠がほとんど残っていないことがあります。W9のうちに予約を済ませてください。

4ネット試験の結果で W11 が分かれる

ネット試験の結果は、試験の終了と同時に分かります。結果によって W11 の使い方が分かれます。

合格した場合

2級の学習はここで終わりです。合格証はデジタル合格証で、受験の3時間後ほどでマイページから出力できます。紙の合格証書は発行されません。

不合格だった場合

スコアレポートの大問別の得点を、目標得点と並べます。目標との差が大きい大問が、W11で時間を寄せる先です。問題の中身は持ち帰れないので、配分を決める根拠はこの得点と、退室直後に書き出した記憶の2つです。W11 の時間数は変えず、中身の配分だけを変えます。

不合格だった場合は、次の表に得点を書き込み、目標との差を出してください。大問の配点は公表されておらず、表の配点は予備校の分析による通説です（UNIT 01 §4）。

大問配点（通説）目標取得目標との差
第1問 仕訳2016
第2問 連結・個別論点2014
第3問 決算2016
第4問 工業簿記2824
第5問 標準・CVP・直接1210

差が出たら、W11 の配分を次のように寄せます。

  1. 差が最も大きい大問に、間違いノート反復4時間のうち2時間を寄せる。残り2時間は他の大問に均等に使う
  2. セット5・セット6の解き直しは、差の大きい大問から始める。時間が足りなくなっても、弱い大問の解き直しは残る
  3. 第1問の差が大きいなら、UNIT 03 の頻出仕訳30問を先に回す。第4問は、スコアレポートが大問単位なので(1)と(2)の区別がつかない。退室直後に書き出した記憶から第4問(1)の仕訳で落としたと分かれば、勘定連絡図の描き直しを先にする
不合格の日に計画を組み直さない

本番の1週間前に不合格を受け取ると、「全部やり直さなければ」と感じて新しい問題集や苦手論点のテキストを最初から開きたくなります。これは直前週で最も高くつく判断です。1週間で新しく身につくものはほとんどなく、既に解けるはずの問題の精度が落ちます。

ネット試験の不合格は、W11 でどこに時間を寄せるかが分かったということです。上の3つの寄せ方以外は、予定どおり進めてください。

なぜ直前週だけ負荷を落とすのか

W11 は試験日を除くと実質6日しかありません。ほかの週と同じ23時間を入れると1日あたり約3.8時間になり、11週間で最も密度の高い週が試験の直前に来ます。試験の2〜3日前の睡眠は、そのまま当日の集中力と計算の精度になります。

そこで本番形式のセットは11/9〜11/12の4日間で終え、11/13（金）〜11/15（日）は1日2時間以内にします。この3日間は新しい問題に手を出さず、一度間違えたものの再確認だけに絞ります。

直前に「まだ解いていない問題」を探さない

直前週に新しい予想問題を解くと、見慣れない出題に当たって解けないことがあります。それで分かるのは「この1問が解けない」ことだけで、残り数日で埋められるものではありません。代わりに自信が削れます。

直前週に回すのは、自分が一度間違えて、解き直して、解けるようになったものだけです。これなら確実に点に結びつき、「解ける」という手応えを持ったまま本番に入れます。

統一試験の持ち物

統一試験（紙の試験）は、ネット試験と持ち物が違います。筆記用具は自分で持参します（HBまたはBの黒鉛筆、シャープペン、消しゴム）。計算機器はそろばんか電卓のどちらか1つで、電卓は四則演算の計算機能のみのものに限られます。問題用紙・答案用紙・計算用紙は一体の冊子で配られます。

ネット試験では筆記用具とメモ用紙は会場で用意され、個人の筆記用具は持ち込めません。1週間前にネット試験を受けた感覚のまま準備すると、筆記用具を忘れます。

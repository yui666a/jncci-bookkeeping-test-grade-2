1このユニットの目的

普段は手書きで家計簿をつけている人が、ある日から表計算ソフトで同じ家計簿をつけることになった、と考えてみてください。何にいくら使ったかという中身は1円も変わりません。それでも最初の数日は、どのセルに打つのか、打った数字がちゃんと入ったのか、前の月の欄はどこへ行ったのかで手が止まります。中身を知っていることと、その道具で速く正確に書けることは別の能力です。

ネット試験（CBT）もこれと同じです。出題範囲も合格の価値も統一試験と変わりません（両者の比較は Phase 0 UNIT 04 §2）。変わるのは答え方と下書きの仕方です。この計画では 11月2日〜8日にネット試験を1回受けます（理由と締切は 同 §4）。その1回を「画面に慣れるだけで終わった」にしないために、受ける前に2時間だけ操作の段取りを作っておきます。

なぜ操作に2時間も使うのか

本番形式の演習で身につくのは、90分で5つの大問を解き切る配分の感覚です。ところがその感覚は紙の問題冊子と、書き込み放題の余白を前提に育っています。ネット試験では問題は画面の中にあり、下書きに使えるのはA4用紙2枚だけです。紙の感覚のまま座ると、最初の10分を「どこに書くか」を決めることに使ってしまいます。その10分を、あらかじめ決めた段取りで0分にするのがこの単元の役目です。

2紙の試験と何が違うのか

日商の「ネット試験に関するQ&A」に書かれている受験の条件を、紙の統一試験と並べます。この単元で断定しているのは、この表に載っている範囲だけです。画面の細かな配置や、ここに書いていない機能の有無は、公式サンプルや教育機関の模擬試験（§6）で自分の目で確かめてください。

この表から出てくる3つの注意

「選んだつもり」と「確定した」は別物

Q&Aはわざわざ「勘定科目の選択は正確に確定させることが必要」と書いています。一覧を開いて科目を目で見つけたことと、その科目が解答欄に入ったことは同じではありません。紙なら書いた字がそのまま答えですが、画面では選んだ後に、解答欄に表示されている科目名を読み直すまでが1回の操作です。

もう1つの落とし穴は、似た名前の科目の取り違えです。「備品減価償却累計額」と「減価償却累計額」、「支払利息」と「支払リース料」のように、頭の数文字だけ見て選ぶと別の科目を掴みます。一覧の並び順はこの教材では確かめていないので、並び方に頼らず、確定した科目名を最後の文字まで読みます。

「試験終了」ボタンは1回押したら終わり

このボタンは提出ボタンではなく、試験そのものを終わらせるボタンです。押した時点で試験が終わります。見直しが済むまで、このボタンには触れないでください。Q&Aの記載では、大問を移動するボタンは画面下部、「試験終了」は画面右下です。どちらも画面の下側にあるので、大問を移動するつもりで押し間違えないよう、押す前にボタンの文字を読みます。

問題が持ち帰れない以上、手元に残るのはスコアレポートだけ

問題もメモ用紙も回収されます。そして出題はランダムなので、落ちて再受験しても同じ問題は出ません。つまりネット試験で得られる復習材料は大問ごとの得点と、自分の記憶だけです。11月上旬の1回を11月15日の統一試験に生かすには、スコアレポートで「どの大問が何点足りなかったか」を見て、W11の残り時間をどこへ振るかを決めます。

3メモ用紙2枚の割り振りを先に決める

紙の試験では、第3問の決算整理事項の横に金額を書き込み、第4問の問題文に線を引き、余白でボックス図を描けます。下書きの場所は問題のすぐ隣にあります。ネット試験では問題は画面の中なので、ボールペンで書き込むことはできません。すべての下書きが、2枚のメモ用紙に集まります。

引っ越しの荷造りで、段ボールに「台所」「寝室」と先に書いておくと、荷ほどきのときに箱を開けて探す手間が消えます。メモ用紙も同じで、書き始める前に区画と名前を決めておけば、見直しのときに「第3問のメモはどこだっけ」と探さずに済みます。

割り振りの具体案

次の割り振りは、Phase 0 UNIT 04 で固定した解答順（第4問 → 第5問 → 第1問 → 第3問 → 第2問）に合わせています。解答順どおりに、用紙1の上から書き進める形です。

工業簿記と商業簿記で用紙を分け、それぞれを解答順に上から使う
この割り振りにする理由
決めごと理由
用紙1を工業簿記、用紙2を商業簿記にする解答順の前半（第4問・第5問）が工業簿記、後半が商業簿記です。1枚目を使い切ってから2枚目に移るだけなので、途中で用紙を行き来しません
第4問に用紙1の3分の2を与える配点が最大（配点は公表されておらず、予備校の分析による通説）で、勘定連絡図やボックス図のような面積を食う図を描く大問です。図が窮屈になると数字を取り違えます
第1問は1題1行で済ませる仕訳そのものは画面に直接入力します。メモに書くのは金額の計算過程だけです。仕訳の形まで書き写すと、同じことを2回書くことになります
第3問に用紙2の半分を与える紙の試験なら問題文の横に書いていた決算整理の金額を、ここに番号つきで1行ずつ並べます。財務諸表の空欄を埋めるとき、この一覧が唯一の手がかりになります
第2問は一番下の残り解答順の最後で、難易度の振れ幅が最も大きい大問です。残った面積と残った時間で取れる分だけ取る、という位置づけを用紙の上でも同じにします
ボールペンは消せない

会場で使えるのはボールペンだけで、自分の消しゴムも持ち込めません。書き間違えたら二重線で消して横に書き直すしかないので、紙の試験より余白を多めに取ります。とくにボックス図や勘定の枠は、最初から少し大きめに描いてください。消して描き直すことができません。

裏面は当てにしない

メモ用紙の裏面に書いてよいかは、この教材では確認できていません。表面だけで収まる割り振りにしておき、当日の案内で裏面が使えると分かったら、それは予備として扱います。

区画の線はメモ用紙が配られてから引く

メモ用紙は会場で配られるものなので、区画はその用紙に引きます。この教材では、試験が始まったら最初の1分で2枚に横線を引いて区画を作り、それぞれに大問の番号を書きます。上の図を覚えておけば迷う要素はありません。演習の段階から、白紙のA4用紙2枚を横に置いて同じ区画で解いてください。本番で初めてこの割り振りを試すと、それ自体が迷いの種になります。

4画面の問題を読みながら下書きする手順

紙の試験では、問題文に印をつけながら読むことで「どこまで処理したか」が目に見えていました。画面上の問題文にはボールペンで印をつけられないので、処理済みかどうかはメモ用紙の側で分かるようにします。その前提で、1つの大問を次の順に進めます。

  1. 大問を開いたら、先に答える欄の形を見る問題文を頭から読む前に、画面のどこに何を答えるのか（仕訳か、金額の空欄か、科目名の空欄か）を確かめます。何を求められているかを知ってから読むと、必要な数字だけを拾えます。
  2. メモ用紙の区画に、大問番号と小問番号を書く「4(2)」「3-①」のように、どの設問のメモかを行の頭に書きます。見直しのとき、画面の設問とメモの行を突き合わせる手がかりになります。
  3. 数字は名前つきで書き写す「480,000」だけでなく「期首 480,000」と書きます。画面の問題文と見比べずに済むように、メモだけで意味が分かる形にしておきます。書き写すのは計算に使う数字だけです。
  4. 計算は電卓、結果はメモに1行、すぐ画面に入力する計算結果をメモに書いたら、その場で画面の解答欄に入れます。いくつか計算をためてからまとめて入力すると、どの結果がどの欄のものか分からなくなります。
  5. 入力したら、メモの行を斜線で消す画面に入れ終えた行は、1本の斜線で消します。斜線のない行＝まだ画面に入っていない答えになります。見直しのとき、この斜線が入力漏れを探す地図になります。「印」は、見切って飛ばした欄に付けるもの（UNIT 01 §5）なので、入力済みの目印には使いません。
途中の数字を書かずに済ませる

メモ用紙が2枚しかない以上、書く量は少ないほど助かります。Phase 0 UNIT 03 で練習したメモリー機能（M+ M− MR）を使えば、合計の途中経過を紙に書かずに電卓の中に置いておけます。電卓は統一試験と同じ1台をそのまま持ち込みます。

5入力確定の見直しと時間配分

見直しは「大問を離れる前」と「最後」の2回

紙の答案なら、見開きで全体を眺めて空欄を探せます。ネット試験は大問ボタンで画面を切り替えて移動する仕組みなので、見直しも大問ごとに画面を開き直すことになります。そこで確認を2回に分けます。

1回目 — 大問を離れる前（30秒）
  • 空欄が残っていないか
  • 解答欄に表示されている科目名が、選んだつもりの科目か（似た名前の別の科目を掴んでいないか）
  • 金額のゼロの数。3桁ずつ区切って読む
  • 借方と貸方の欄を取り違えていないか
2回目 — 全問を解き終えてから（戻り枠の最初の1分）
  • 大問ボタンで第1問から第5問まで順に開き直す
  • メモ用紙で斜線で消していない行を探し、画面に入っているか確かめる
  • この後、印を付けて飛ばした欄に戻る。戻っても解けなかった欄には、何か1つは答えを入れる
  • すべて済んでから「試験終了」を押す
なぜ「何か1つは入れる」のか

空欄は確実に0点ですが、入れた答えは当たる可能性があります。仕訳で科目が1つだけ分からないときも、分かる科目と金額は入れておくほうが得です。

ただし解いている途中は、UNIT 01 §5 の見切りのルールが優先です。2分手が止まった欄は、仮の答えを考えずに印を付けて次へ進みます。仮の答えを入れるのは戻り枠です。戻り枠で戻っても解けなかった欄は、「試験終了」を押す前に仮の答えを入れ、空欄を残さないようにします。

90分の時間配分

時間配分そのものは UNIT 01 §4 で決めた目安と通過点をそのまま使います。ネット試験で変わるのは、その中に操作のための時間を埋め込むことだけです。

通過点の中に入れるネット試験の操作

残り時間をどこで見るかを、最初に確かめる

残り時間を画面で確認できるのか、会場の時計で見るのかは、この教材では断定しません。試験が始まったら区画づくりと一緒に、時間の確認手段を1つ決めておきます。「終える時点（経過）」の通過点を覚えておけば、どの確認手段でも遅れに気づけます。

手元の1台（カシオ JW-122CL）の場合

この機種にはタイマー機能がありません。本番形式の演習では、電卓とは別のタイマーで90分と上の通過点を計ってください。本番でもこの電卓で時間は計れないので、時間の確認手段は会場で決めることになります。

6操作訓練ドリル ① 仕訳10問

既習の2級論点から、第1問の形式で仕訳を10問混ぜました。科目の一覧は、本番の選択肢を意識して似た名前の科目や、取り違えやすい科目を多めに入れてあります。1問ごとに、§5の「1回目の見直し」（空欄・科目名・ゼロの数・借方貸方）をしてから採点してください。

このドリルの入力は、本番のプルダウンとは操作が違う

このドリルの科目欄は、文字を打って絞り込み、候補から選ぶ形です。本番の仕訳問題はプルダウンから選ぶ形式なので、手の動きは同じではありません。ここで練習できるのは、似た科目の中から正しい1つを選ぶ判断と、選んだ科目・打った金額を読み直す習慣です。

本物の画面での操作は、次のいずれかで体験してください。

  • 教育機関が公表した日商簿記検定試験 新試験の予想問題について（日商） — 資格の大原・ネットスクールなどの教育機関が作成した2級の予想問題・模擬試験へのリンクがあります。内容は各教育機関の独自作成です
  • 簿記ネット試験サンプルプログラム（日商） — Windows 用の操作体験プログラムです。級の明記はなく、実際の試験より問題が少ない操作体験用です
  • 2級 サンプル問題（日商） — 5セットあり、問題と答案用紙のみで解答・解説はありません
手元のパソコン（Mac）の場合

日商のサンプルプログラムは Windows 用の実行ファイルなので、Mac では動きません。本物に近い画面は、上の教育機関の模擬試験で体験することになります。各教育機関のページで動作環境（Mac で使えるか）を確かめてから時間を取ってください。

Q&Aは操作の条件を「キーボードでの数字・文字入力とマウス操作」と書いています。普段トラックパッドで操作しているなら、このドリルと模擬試験はマウスをつないで解くと、本番に近い手の動きになります。

論点の復習は、電子記録債権・建設仮勘定と除却・契約負債・剰余金の配当・外貨建取引と法人税等・リース取引・貸倒引当金・有価証券の各単元へ。

7操作訓練ドリル ② 金額を打ち込む

ネット試験では、仕訳のほかに金額をキーボードで入力する問題も出ます。第3問の財務諸表や第4問・第5問の空欄を埋める場面です。ここでは計算したらすぐ打ち込み、打った数字を3桁ずつ区切って読み直すところまでを1つの動作として練習します。

カンマを自分で打つかどうかは、模擬試験で確かめる

このドリルの入力欄は、数字だけを打てば自動で3桁ごとに区切られます。本番の金額欄でカンマを打つ必要があるのか、打ってよいのか、自動で区切られるのかは、この教材では断定しません。§6に挙げた模擬試験で1度確かめ、本番と同じ打ち方で練習してください。

8受験当日の流れ

当日に迷うと、そのぶん頭の余力が削られます。段取りは前日までにすべて決めておきます。

  1. 予約の変更は3日前までネット試験の予約・変更・キャンセルは受験日の3日前までです。2日前からは変更できません。体調や仕事の都合で日程を動かす可能性があるなら、3日前の時点で判断します。
  2. 持ち物は本人確認証と電卓本人確認証がないと受験できず、受験料も返金されません。電卓は統一試験で使う1台と同じものを持っていきます。筆記用具は持ち込めないので、持っていく必要もありません。
  3. 始まったら、区画づくりと時間の確認手段§3の区画をメモ用紙に引き、§5の時間の確認手段を決めます。
  4. 第1問の表示が崩れていたら、ほかの大問ボタンを押してから戻る使用するパソコンによっては、開始直後に第1問が正常に表示されないことがあります。そのときはほかの大問のボタンを押し、第1問へ戻ると正常に表示されます。この解答順では最初に第4問のボタンを押すので、戻ってきたときに確かめれば足ります。
  5. トイレに立った時間は戻ってこないトイレは挙手して試験官に確認すれば行けますが、席を離れた時間分の延長はありません。試験の前に済ませておきます。
  6. 早く終わったら「試験終了」を押す途中退室という扱いはありません。見直しが済んでいれば「試験終了」を押し、スコアレポートを印刷して受け取ってから退室します。
  7. 退室したら、記憶を書き出して得点を記録する会場を出たらすぐ、詰まった論点、目安の時間を超えた大問、手応えのなかった論点名を思い出せる限り書き出します。問題もメモ用紙も手元に残らないので、記憶は時間が経つほど戻りません。スコアレポートの大問ごとの得点は、UNIT 01 §8 の得点記録に6セットとは別の1行として書き足します。デジタル合格証は、受験後3時間ほどでマイページから出力できます。
再受験で同じ問題は出ない

出題はランダムなので、1回目に出た問題を覚えて2回目に備えることはできません。11月上旬の1回で見るべきなのは問題ではなく、自分がどの大問で時間と点を落としたかです。スコアレポートの大問別得点は、その答え合わせのためにあります。

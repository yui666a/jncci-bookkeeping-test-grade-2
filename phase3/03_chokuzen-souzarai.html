1直前週のルール — 足さない・詰めない・眠る

試験の前日に、まだ解いたことのない予想問題を1回分解いたとします。見慣れない出題が1問あって、解けませんでした。そこから分かるのは「この1問が解けない」ということだけです。残り1日でその論点を組み立て直す時間はありません。得られるのは不安だけで、点は増えません。

反対に、自分が一度間違えて、解き直して、解けるようになった問題をもう一度解いたとします。今度は解けます。これは本番で同じ型が出たときにそのまま点になりますし、「解ける」という手応えを持ったまま試験会場に入れます。直前週の時間は、この2つのどちらに使っても同じ1時間です。

直前週の3つのルール
  1. 新しい論点を足さない。試験前の3日間（11/13〜11/15）は新しい問題にも手を出さない回すのは既習の内容だけです。11/9〜11/12 の本番形式2セットは計画どおり解きます。11/13 からは、まだ開いていない予想問題集の回や、これまで使っていなかった教材を開かないでください。見慣れない出題に当たって得られるのは、上で見たとおり不安だけです。
  2. 試験の2日前と前日（11/13・11/14）は1日2時間以内、当日は試験だけ本番形式のセットは11/12までに終え、最後の3日間は再確認だけにします。W11は試験日を除くと実質6日しかなく、ほかの週と同じ時間を入れると11週間で最も密度の高い週が試験直前に来てしまうため、この週だけ全体を16時間に落としています。
  3. 睡眠を削らない試験の2〜3日前の睡眠は、当日の集中力と計算の精度にそのまま出ます。直前の数時間の追い込みで増える知識より、寝不足で起きる電卓の打ち間違いや読み落としのほうが高くつきます。
なぜ「減らす」ことが対策になるのか

2級の合格点は70点で、満点は要りません。直前週に点を伸ばす手段は、知らない論点を1つ覚えることではなく、知っている論点で落とす点を減らすことです。後者の失点の多くは、計算ミスと読み違え——つまり疲れと焦りから来ます。

だから直前週は、量を減らして精度を上げる週になります。この週に積むべきものは知識ではなく、「いつもの手順で、いつもどおり解ける」という状態です。

1週間の割り振りは Phase 3 目次 の W11 の表にあります。この単元を使うのは、11/9〜11/12 の間違いノートの時間（0.5h × 4日）と、11/13・11/14 の2日間（各2h）です。11/13 は勘定連絡図の描き直し（約30分）と工業簿記10問（約30分）と間違いノート1h、11/14 は商業簿記20問（約60分）と間違いノート1hです。

「念のため」の1冊を買わない

直前週にいちばん起きやすいのは、不安から新しい問題集や直前対策本を買い足すことです。その本の最初の数問で知らない論点に出会うと、残りの日数をそこに吸い取られます。手元にある自分の間違いノートこそが、自分専用の直前対策本です。ほかの誰の本にも、自分の弱点はこれほど正確には載っていません。

自分の受験予定の場合

11/2〜11/8 のネット試験を1回受ける計画です。合格していれば、このページは使いません。不合格だった場合は、スコアレポートで差の大きかった大問のタグを、間違いノートの反復（次の節）で先に回してください。紙の間違いノート3時間のうち2時間をそのタグに寄せ、復習ドリルの1時間はそのまま回します。

2間違いノートの反復（4時間）

間違いノートには、Phase 0 から書きためてきた誤答が入っています。書き方は Phase 0 UNIT 04 で作り、実戦期の項目（正しい判断の手がかり）は UNIT 01 の第9節 で足しました。この節では、それを4時間でどう回すかだけを扱います。

誤りの記録は2か所にあります。予想問題集・サンプル問題・ネット試験で落とした点は紙（または自分で書いた）間違いノートに、この教材のドリルで間違えた設問は復習ドリルに自動で集まっています。4時間はこの2つを両方回します。

紙の間違いノートの回し方

日付順に最初から読み返すのは避けてください。1件ずつ別の論点が並ぶので、同じ穴が何度も開いていることに気づけません。論点タグでまとめて並べ直してから回します。

  1. タグごとに件数を数える付箋でも、表計算の並べ替えでも構いません。「減価償却 5件」「連結/開始仕訳 3件」「時間配分/第4問(2) 2件」のように、タグごとの件数を出します。
  2. 件数の多いタグから回す同じタグが3件以上ある論点は、個別の失敗ではなく構造的な穴です。点に戻ってくる量が最も多いので、ここに先に時間を使います。1件しかないタグは後回しで構いません。
  3. 「問題の要点」だけを見て、答えを隠して解くノートの「正解」の欄を手で隠し、要点の1〜2行から自分で仕訳や金額を書きます。読んで「そうだった」と思うだけでは、本番で白紙から書ける保証になりません。
  4. 「正しい判断の手がかり」を声に出さずに言う解けたら、その問題文のどの言葉を見れば正しい処理を選べたかを、ノートを見る前に言ってみます。本番で効くのはこの1行です。
  5. 印を付けて、次の周回を軽くする白紙から正しく書けたものには印を1つ付けます。2回続けて印が付いた件は、次の周回から外します。回すたびに対象が減っていくので、4時間の後半ほど本当に危ない件に時間が集中します。
「なぜ間違えたか」の分類で、回し方を変える

「なぜ間違えたか」の欄の分類（原因の3分類と、時間で落とした取りこぼし）によって、反復でやることが違います。

原因反復でやること
知識の欠落答えを隠して解き直す。書けなければ、該当する単元の本文に戻って理由を読み直す。この分類だけは、単元に戻る価値があります
読み違え解き直しは要りません。「正しい判断の手がかり」の1行だけを読み、問題文のどの言葉に印を付けるべきだったかを確かめる。1件30秒で足ります
計算ミス同じ計算を電卓でもう一度打ち、ミスした操作（メモリーの消し忘れ、GTの二重加算など）を再現する。テキストに戻っても直りません
取りこぼし（時間配分）知識の問題ではないので、単元には戻りません。遅れた大問を1つ選び、通過点つきで時間を計って解き直します（その大問の目安の時間。第4問なら25分）。どの欄で2分・5分の見切りを使うべきだったかを確かめる

読み違えと計算ミスは1件あたりの時間が短いので、件数が多くても4時間の中で全件に目を通せます。時間がかかるのは知識の欠落と取りこぼしです。取りこぼしは同じ大問のタグをまとめ、大問1つにつき1回解き直せば足ります。

復習ドリルの使い方

復習ドリル は、この教材の単元ドリルで一度でも間違えた設問を、単元をまたいで集めて再出題するページです。3回続けて正解すると一覧から消えます。並び順は最後に間違えてから時間が経った順で、忘れかけているものが先に来ます。

  1. 全体の件数を見るページ上部に要復習の件数が出ます。単元が2つ以上あれば、単元ごとの絞り込みボタンも出ます。
  2. 件数の多い単元から絞り込んで解く紙の間違いノートと同じ考え方です。同じ単元に誤答が固まっていれば、そこが穴です。
  3. 間違えたら、単元へ戻る設問の上の単元名を押すと、その設問のある単元のドリルへ飛べます。解説だけでなく、その論点の本文を読み直してください。
  4. 消えなかった設問を最後にもう一周4時間の最後に残っている設問が、試験の朝に見返すものです。
記録は「開いた場所」ごとに別々に保存される

ドリルの正誤はブラウザの中に保存されます。この保存場所はページを開いたアドレスの始まりごとに分かれています。公開サイトで解いた記録と、手元のファイルを直接開いて解いた記録は、同じ設問でも別々に保存され、互いに見えません。

そのため、単元を解いてきたのと同じ場所で復習ドリルを開いてください。公開サイトで解いてきたなら公開サイトの復習ドリルを、手元で配信して解いてきたなら同じアドレスの復習ドリルを使います。

手元のファイルを直接開いている場合、復習ドリルは設問データを読み込めません（画面に案内が出ます）。その場合は 学習の記録 の「要復習」の一覧を使ってください。ファイルを直接開いた状態でも動き、設問名を押すとその単元へ飛べます。

4時間の配分の目安

紙の間違いノートに3時間、復習ドリルに1時間が目安です。予想問題集で落とした点は、本番と同じ形式での判断の誤りなので、そのまま点に直結します。復習ドリルは論点ごとの知識の穴を機械的に潰す道具として、紙のノートの「知識の欠落」を補う位置づけで使います。

ネット試験のスコアレポートで目標との差が大きい大問が分かっている場合は、紙の3時間のうち2時間をその大問のタグに寄せ、残り1時間を他のタグに使います。復習ドリルの1時間はそのまま回します（Phase 3 目次 §4）。

3勘定連絡図をもう一度、何も見ずに描く

地図を持たずに知らない街を歩くと、1つ曲がり角を間違えただけで自分がどこにいるか分からなくなります。工業簿記の第4問・第5問で起きるのも同じことです。「この差異はどの勘定からどこへ行くのか」「この仕訳の相手はどの勘定か」で迷うのは、頭の中の地図が薄れているからです。

その地図が Phase 0 UNIT 02 勘定連絡図 です。Phase 0 で描けるようにした図に、Phase 1 で差異の勘定や本社・工場の勘定が乗りました。直前週にもう一度、何も見ずに白紙に描きます。描いて下の自己チェックで点検し、描けなかった線を描き足すまでで約30分です。描き方の手順は UNIT 02 の第6節 にあります。

なぜ直前にもう一度描くのか

第4問(1)の仕訳3題は、ほぼすべてこの図のどこか1本の矢印です。材料を消費したら材料から仕掛品か製造間接費へ、予定配賦なら製造間接費から仕掛品へ、差異を振り替えるなら製造間接費から配賦差異へ。描けない線が、本番で落とす仕訳を示しています。

描き終わってから次の節の工業簿記10問を解くと、1問ごとに「いま図のどの矢印を書いているか」が見えるはずです。見えない問題があれば、そこが図の中で薄い場所です。

4頻出仕訳の総ざらい — 商業簿記 20問

第1問は仕訳5題で20点、第4問(1)は工業簿記の仕訳3題で12点（配点は公表されておらず、予備校の分析による通説）。合わせて32点が仕訳だけで決まります。合格点70点の半分近くです。しかも仕訳は、同じ型が形を変えて繰り返し出ます。反復した回数がそのまま点になる、最も確実な場所です。

この節と次の節で、W1〜W9 で学んだ2級の論点から、第1問・第4問(1)で繰り返し出る型を30問並べました。新しい処理は1つもありません。全問が、すでに学んだ単元のどこかに根拠を持っています。各問の解説の最後に、その単元へのリンクを付けています。

このうち連結の開始仕訳と、連結の貸倒引当金の修正の2問は、主に第2問（連結精算表など）で問われる論点です。第2問でも1行ずつの仕訳の型が土台になるので、その型を確かめるために入れています。

目安の時間は、商業簿記20問が約60分、工業簿記10問が約30分です（1問3分）。工業簿記10問は、第3節の勘定連絡図の描き直し（約30分）を済ませてから解きます。

解き方
  • 1問3分を目安にします。本番の第1問は5題を15分で解く配分です（UNIT 01 の第4節）
  • 解答欄は常に4行です。行数から正解の科目数は読めません。本番と同じく、使わない行は空けたままで構いません
  • 勘定科目は一覧から選びます。本番でも、問題文が示す勘定科目の中から選んで答えます
  • 同じ勘定科目は、借方・貸方それぞれ1行にまとめます。本番のネット試験では、1つの設問で同じ科目を借方（または貸方）に2回使うと不正解になります（UNIT 02 §2）。このドリルの正解も、同じ科目を1行にまとめた形で作っています
  • 間違えた問題は、リンク先の単元に戻って本文を読み直してから、ここで解き直してください。間違えた設問は復習ドリルにも載ります
総ざらいで最も落としやすい3か所

①未決算の金額は保険契約の金額（保険金の上限）ではない。焼失した資産の帳簿価額です。保険金の額は、確定するまで仕訳に出てきません。

②契約資産と売掛金を取り違える。請求する権利が「他の約束を果たすこと」を条件にしているうちは契約資産です。条件が付いていなければ売掛金です。

③連結の開始仕訳で、過年度の損益を利益剰余金に置き換え忘れる。前期ののれん償却や非支配株主に帰属する当期純利益は、開始仕訳ではすべて利益剰余金（当期首残高）になります。

5頻出仕訳の総ざらい — 工業簿記 10問

第4問(1)の仕訳3題は、費目別計算・製造間接費の配賦・差異の振替・本社工場会計・標準原価計算の記帳から出ます。どれも勘定連絡図の上の1本の矢印です。前の節で描いた図を横に置いたまま解いてください。

工業簿記の仕訳は、問題文の「勘定の一覧」から選ぶ

第4問(1)では、使える勘定科目が問題文で指定されます。工場会計を独立させた問題では、工場に置かれた勘定の一覧も示されます。一覧にない科目は使えません。

この節では、問題文に断りがない限り、材料・賃金・給料・経費・製造間接費・仕掛品・製品・売上原価と各差異勘定を使う前提で解いてください。

6試験当日の手順

当日の朝に「何を持っていくか」「どこから解くか」を考え始めると、それだけで集中力を使います。決められることはすべて前日までに決めて、当日は手順どおりに動くだけにしておきます。

統一試験の持ち物と規定

統一試験（紙の試験）とネット試験では、持ち物が違います。ネット試験では筆記用具とメモ用紙が会場で用意され、個人の筆記用具は持ち込めません。1週間前にネット試験を受けた感覚のまま準備すると、筆記用具を忘れます。

統一試験の持ち物（日商「簿記2級 試験科目・注意事項」による）
もの規定
身分証明書原則として氏名・生年月日・顔写真のいずれも確認できるもの（運転免許証、旅券（パスポート）、社員証、学生証など）を持参する
筆記用具HBまたはBの黒鉛筆、シャープペン、消しゴム。自分で持参する。ラインマーカー・色鉛筆・定規などは使えない
計算機器そろばん・電卓のどちらか1つ。電卓は計算機能（四則演算）のみのもの。印刷・音声・プログラム・辞書の機能があるものは不可。日数計算、時間計算、換算、税計算、検算（音の出ないものに限る）の機能は使ってよい
受験票など受験地の商工会議所から届いた案内に従う。持ち物や集合時刻は会場ごとの案内で確認する

試験時間は90分です。問題用紙・答案用紙・計算用紙は一体の冊子で配られます。勘定連絡図やボックス図は、この冊子の計算用紙に描きます。

電卓は前日のうちに2つのことを確かめる

①端数処理の設定。ラウンドセレクター（端数処理の切替）が付いている電卓なら、切り捨てや四捨五入の位置になっていないか確かめます。割り算の結果が勝手に丸められると、配賦率が割り切れない問題で答えがずれます（Phase 0 UNIT 03）。

②電池と表示。表示が薄くなっていないか、すべてのキーが反応するかを確かめます。会場で気づいても替えは効きません。

手元の1台（カシオ JW-122CL）の場合

この機種には税計算と時間計算のキーがありますが、どちらも統一試験の規定で使ってよいとされている機能です。印刷・音声・プログラム・辞書の機能はないので、そのまま持ち込めます（原本は reference/casio_jw-122cl_manual.pdf）。

前日に確かめるのはラウンドセレクターが F になっていることです。F のあいだは小数点セレクターが働かないので、そちらは触らなくて構いません。税率の設定は簿記の計算では使わないので、変える必要はありません。

タイマー機能はないので、時間の確認は電卓ではできません。本番で時刻をどう確かめるかは、受験地の案内で確認しておきます。

前日から試験開始までの流れ

  1. 前日の昼までに持ち物を揃える身分証明書、筆記用具（鉛筆またはシャープペンを複数本、消しゴム）、電卓、受験地から届いた案内。電卓の設定と電池を確かめ、1か所にまとめて置きます。
  2. 前日の夜に、解答順を頭の中で1回通す冊子を開いたら第4問のページへ。計算用紙に勘定連絡図を描く。25分で第5問へ、35分で第1問へ、50分で第3問へ、70分で第2問へ。問題は解かず、手順だけを5分でたどります。演習と同じ動きを本番の前に一度なぞっておくと、当日に考えることが減ります。
  3. 前日は早めに寝るこの単元でいちばん効く対策です。
  4. 当日の朝は、間違いノートの最後に残った件だけを見る第2節の反復で最後まで印が揃わなかった件と、復習ドリルに残った設問だけです。新しい問題は解きません。
  5. 試験開始の合図のあと、第4問のページを開く第1問から順にめくらず、まっすぐ第4問へ行きます。問題文を読む前に、計算用紙に勘定連絡図を描いてしまっても構いません。
試験中に予定どおりいかなかったとき

通過点に遅れていたら、今の大問を切り上げて次へ進みます。飛ばした欄は、最後の5分の戻り枠で戻ります。第2問が難しかったときも、そこで粘らないために最後に置いてあるのだと思い出してください。見切りのルールは UNIT 01 の第5節 のとおりです。演習で守ってきたルールを、本番でもそのまま使います。

## 学習者個人の環境に関する原本

会計の内容ではなく、学習者が実際に使う道具の仕様を確かめるための原本である。
機種によって操作が違う事柄（電卓のセレクター、定数計算など）を教材に書くとき、
記憶や量販店の商品説明ではなくこれを根拠にする。

この説明書から確定した事実は2つある。**小数点セレクターに F の位置はない**
（選択肢は 4 / 3 / 2 / 1 / 0 / ADD2）。そして小数点セレクターは
「ラウンドセレクターが「F」以外の場合に機能します」。したがって端数処理を
止めるにはラウンドセレクターを F にすれば足り、小数点セレクターの位置は問わない。

定数計算は四則すべて演算キーを2回押す方式で記載されている（画面に「K」）。
割り算は先に打った数が割る数の定数になる。

一般公開する際、この行は残してよい。教材本文の一般論はこの機種に依存しておらず、
機種固有の記述は `.callout--mine` に分離してある。
